## 📌 About the Project
FinSight Analytics is a web application focused on data auditing and visualization. It empowers users to upload raw financial spreadsheets and processes the information locally directly within the browser. This approach ensures strict data privacy while generating interactive visual dashboards, expense distribution charts, and trend forecasting.

## 🚀 Key Features
- **Local Data Processing:** Reads and processes raw spreadsheet data entirely in the browser (no server uploads required, ensuring data privacy).
- **Visual Dashboards:** Generates clear, interactive charts for immediate financial auditing.
- **Trend Forecasting:** Analyzes historical data to provide future expense distribution insights.
- **User-Friendly Interface:** Simplifies complex data manipulation into an intuitive front-end experience.

## 🛠️ Technologies Used
- JavaScript (Data Manipulation & Logic)
- Front-End (HTML5, CSS3, UI/UX Design)
- Charting & Data Visualization Libraries
